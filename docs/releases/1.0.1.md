# Role Weaver Server Add-on 1.0.1

Version **1.0.1** is a normal patch release for the Linux Server Add-on and the
new Windows Remote Installer. GitHub tag: `v1.0.1`.

## Downloads

- **RoleWeaver-Server-Addon-1.0.1.tar.gz** installs directly on an existing
  Linux NWN:EE/NWNX host. It includes the browser-based guided setup launched by
  `bash setup.sh gui`.
- **RoleWeaver-Remote-Installer-1.0.1.zip** runs on Windows, tests SSH access,
  uploads the bundled Linux add-on, creates a loopback SSH tunnel and opens the
  same guided setup in the Windows browser. The matching add-on and checksum are
  inside the ZIP and selected automatically.

The editable Linux demo remains available from version 1.0.0. This patch does
not replace that download.

## Changes

- Adds the separate Windows Remote Installer with password or key-based OpenSSH,
  persistent diagnostic logging and a standalone SSH-login test.
- Bundles the exact Linux add-on used by the installer and rejects archives that
  lack the graphical setup entry point.
- Adds graphical Linux setup with guided server paths, dependency checks,
  preparation, installation, verification and update/rollback steps.
- Companion AI now starts enabled for each player login when the server owner has
  enabled the feature. A player's in-game off switch remains in effect for that login.
- Improves familiar inventory preparation, nearby awareness documentation and the
  demo supplies chest used for companion errands.
- Makes Captain Beran's patrol recover from a bounded number of confirmed stale
  movement rejections while preserving DM stop and uncertainty safeguards.
- Adds maintained tooling for the separate portable Windows QEMU demo.

## Updating

Back up Role Weaver data and the NWN world before updating. Direct Linux users can
extract the new archive and follow `START_HERE.md`. Windows administrators can
extract the Remote Installer ZIP, run the executable, test SSH login and continue
through the browser guide. The installer keeps the dashboard and Redis on Linux
loopback and reaches setup through SSH.

Existing configuration, credentials, memories and translation caches are preserved
by the managed update path. Updated bridge scripts still require the server owner's
normal module/override installation and an NWN restart before game-side behavior
changes. Review generated instructions rather than replacing a modified module.

## Limits

The Windows Remote Installer administers a Linux host; it is not a native Windows
NWNX server. Windows OpenSSH Client and working SSH access are required. The Linux
host still needs NWN:EE, compatible NWNX, Redis, Python and the documented build
dependencies. Code signing is not included, so Windows may display a reputation
warning for the installer executable.

Before deployment, read `docs/SECURITY_AND_LIMITS.md` and the version 1.0.1
release review included with the source.
