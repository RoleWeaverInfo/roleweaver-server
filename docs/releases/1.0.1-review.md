# Version 1.0.1 release review

Prepared **2026-10-06**. Application and Server Add-on distribution **1.0.1**,
stable release channel. This record covers the Linux Server Add-on and Windows
Remote Installer. The version 1.0.0 Linux demo remains a separate download.

## Completed source checks

- Python formatting check passes for application, tools, tests and demo sources.
- Focused companion, patrol, demo, remote-installer and portable-demo tests pass.
- Node draft-recovery and companion-template checks pass.
- Native Windows demo launcher and model-loading regression checks pass.
- Windows Remote Installer compiles and its SSH/upload path was exercised against
  the Ubuntu VMware test host.
- The installer successfully tested SSH, uploaded the bundled add-on, created the
  tunnel and opened graphical setup from Windows.

The full Windows Python run has one platform-specific cleanup failure when deleting
an SQLite WAL file immediately after terminating the recovery-test subprocess.
The application assertions complete before that cleanup point. The normal GitHub
Linux matrix remains the release gate.

## Package checks

The automated release workflow builds the Linux add-on first and passes that exact
archive to the Windows job. `tools/verify_release.py` checks safe archive paths,
the single top-level folder, setup launchers, release metadata, the complete source
manifest, external checksums, bundled archive identity and the Windows executable
header. A version tag must match the application version.

Final package filenames and SHA-256 values are recorded after the release commit is
built. A version tag creates a **draft** GitHub release; publication remains a human
review step.

## Remaining deployment checks

- Fresh-host Ubuntu installation using only packaged instructions.
- SSH-key authentication from a second clean Windows system.
- Upgrade and rollback rehearsal against a copy of a modified persistent world.
- Extended multiplayer, interruption/recovery and server-load testing.
- Optional Windows code signing and SmartScreen reputation work.
