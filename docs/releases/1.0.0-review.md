# Version 1.0.0 release review

Reviewed **2026-10-02**. Distribution and runtime **1.0.0**, stable release channel.
The owner selected version 1.0 for this release. The GitHub release records the
published tag and download assets; this document records verification scope.

## Contents and documentation

- Separate Demo and Server Add-on downloads, each with START_HERE.md and guided
  setup. The add-on keeps an established world's module in its existing location.
- The complete editable demo is retained: three areas, Royal Guide, investigation,
  11 AI profiles, six world documents, nine access-lore entries, merchants, patrol
  and the forest robbery/troll hostage encounters.
- Companion controls and editable familiar templates, dashboard login, translation,
  recovery and diagnostics are included with current sources and documentation.
- Removed superseded milestone reports, old release notes and setup stubs. Prior
  releases remain available in Git history/tags. Corrected stale payment, persistent
  director, backup and installation descriptions; kept a curated documentation index.
- Packaging uses authored content instead of runtime databases. Credentials,
  private settings, player histories, translation caches, saves, logs and backups
  are excluded. Updating an existing installation still preserves its data.
- Unreviewed JSON/CSV exports are rejected, demo seed runtime fields are checked,
  and relative Markdown links are validated against each archive's actual contents.

The fresh demo setup used an isolated staging directory with the existing
NWN/NWNX installation and compiler. It is **not** a clean-machine dependency or
system-service installation rehearsal. No provider requests were made for these
checks. Tests use synthetic fixtures and mocks where appropriate.

The installed game world, NPC memories and translation database were not reset.
NWN was already stopped and remained stopped. No game session, native crash,
multiplayer test or production deployment was performed during this packaging work.

Earlier user playtests include encounters, companions and two simultaneous
players viewing German and Spanish dialogue privately while public spoken text
remained English. Those are prior feedback, not a new playtest of the final archives.

- Upgrade/rollback rehearsal on a copied installation and independent integration
  on a modified persistent world.
- Final player walkthrough and the previously deferred extended multiplayer and
  real interruption/recovery exercises.
- Inherited creature blueprint and module asset provenance/redistribution review;
  see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). Prior publication does
  not resolve that review.
- Optional native translation adapter remains specific to Linux x86-64
  NWN/NWNX 8193.37-17 with matching Core/source. This packaging pass compiled
  NWScript; it did not rebuild or retest the C++ adapter's engine hooks.
- Publication uses the exact committed source tagged `v1.0.0`, both archives and
  their SHA-256 sidecars. Public download verification is recorded in the release
  process; a GitHub release is separate from forum/Vault announcements.
